# بسته‌های آماده‌ی نصب

هر پوشه مستقل است. قبل از هر نصب، فایل قدیمی روی هاست را با پسوند `.bak` نگه دارید (برگشت = عوض کردن اسم).

## 00-diag — تشخیص محیط هاست (فقط‌خواندنی)
1. فایل `mm-diag-ad2f4f36c398b026.php` را در ریشه‌ی سایت (کنار `index.php`) آپلود کنید.
2. این آدرس را باز کنید و کل متن را برای من بفرستید:
   `https://mehdimehrabi.ir/mm-diag-ad2f4f36c398b026.php?k=ad2f4f36c398b026`
3. بلافاصله بعدش فایل را از هاست حذف کنید.

## 01-sitemap — رفع خطای نقشه‌ی سایت
جایگزین `sitemap.php` در ریشه‌ی سایت. فقط ربات‌های گوگل از آن استفاده می‌کنند؛ به دانشجوها و ویدیو ربطی ندارد.
بعد از نصب `https://mehdimehrabi.ir/sitemap.xml` را باز کنید؛ باید لیست آدرس‌ها را ببینید.
