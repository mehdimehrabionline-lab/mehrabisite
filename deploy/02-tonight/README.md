# بسته‌ی «سریع‌تر + تحمل‌پذیر در برابر قطعی» — مرحله‌به‌مرحله

سه زیپ:

| زیپ | چه می‌کند | ریسک |
|---|---|---|
| `1-new-files.zip` | فقط فایل‌های **جدید** (فونت، کتابخانه، کش، صفحه‌های `*-test`) — هیچ فایل زنده‌ای را عوض نمی‌کند | صفر |
| `2-swap-main.zip` | نسخه‌ی نهایی ۶ صفحه + `sitemap.php` — فایل‌های زنده را **جایگزین** می‌کند | کم (بعد از تست؛ برگشت ≈ ۱ دقیقه) |
| `3-swap-blog-optional.zip` | فونت/کتابخانه‌ی محلی برای دو صفحه‌ی بلاگ | اختیاری |

## ۰) بکاپ (۳ دقیقه)
- cPanel ← File Manager ← در پوشه‌ی **home** (بالاتر از `public_html`) یک پوشه‌ی جدید بساز: `backup-1011`
- همین حالا از این فایل‌های `public_html` در آن پوشه **Copy** بگیر (سمت راست‌کلیک ← Copy):
  `watch.html  dashboard.html  course.html  register.html  index.php  payment-callback.html  sitemap.php`
  (و در صورت نصب فایل ۳: `blog.html  blog-post.html`)
- بکاپ باید **بیرون** از `public_html` باشد (نسخه‌ی `.bak` داخل public_html از بیرون قابل دیدن است).

## ۱) نصب فایل‌های جدید
1. `1-new-files.zip` را در `public_html` آپلود کن ← روی آن راست‌کلیک ← **Extract** (مقصد: `/public_html`).
2. این دو آدرس را در مرورگر باز کن؛ باید متن/کد ببینی، نه ۴۰۴:
   - `https://mehdimehrabi.ir/assets/fonts/fonts.css`
   - `https://mehdimehrabi.ir/assets/supabase.min.js`

## ۲) تست با حساب خودت (۱۰ دقیقه)؛ به هیچ‌کدام از هنرجوها اثر ندارد
با حسابی که دوره دارد وارد باش (یا در حالت ناشناس وارد شو):
| آدرس | باید ببینی |
|---|---|
| `/dashboard-test.html` | کارت دوره‌ها؛ فونت درست؛ گوشه‌ی پایین‌چپ برچسب TEST |
| دکمه‌ی «مشاهده ویدیوها» (می‌رود به `watch-test.html`) | لیست جلسات؛ پخش ویدیو؛ جلو/عقب بردن؛ دانلود پیوست |
| `/course-test.html?slug=hoosh-masnoee` | صفحه‌ی دوره‌ی کامل؛ دکمه‌ی «مشاهده ویدیوها» برای خریدار |
| `/index-test.php` | کاملاً مثل صفحه‌ی اصلی (دوره‌ها، نظرات، ویدیوی اسکرول) |
| `/register-test.html` (در **حالت ناشناس**) | شماره را با ارقام **فارسی** بزن (کیبورد فارسی گوشی) ← باید کد پیامکی بیاید |

**تست قطعی (اختیاری ولی مهم؛ فقط قبل از مرحله‌ی ۳):**
1. `watch-test.html` را یک بار باز کن و ۱ دقیقه صبر کن.
2. در `public_html` یک فایل خالی با نام `mm-sb-down.flag` بساز (File Manager ← New File).
3. صفحه را Ctrl+F5 کن ← باید همچنان لیست جلسات بیاید و ویدیو پخش شود (یعنی از کش خوانده می‌شود).
4. **همان لحظه** فایل `mm-sb-down.flag` را حذف کن.

## ۳) جایگزینی (فقط اگر مرحله‌ی ۲ سالم بود)
1. مطمئن شو بکاپ مرحله‌ی ۰ انجام شده.
2. `2-swap-main.zip` را در `public_html` آپلود کن ← Extract (فایل‌های قدیمی را بازنویسی می‌کند).
3. سریع نگاه کن: صفحه‌ی اصلی، یک صفحه‌ی دوره، `/dashboard.html`، یک ویدیو.
4. (اختیاری) همین کار را با `3-swap-blog-optional.zip`.

**برگشت:** فایل‌های `backup-1011` را روی `public_html` Copy کن (Overwrite). فایل‌های جدید (`*2.php`، `assets/`) می‌توانند بمانند.

## ۴) پاکسازی
- حذف: `watch-test.html  dashboard-test.html  course-test.html  register-test.html  index-test.php`
- مطمئن شو `mm-sb-down.flag` وجود ندارد (وجودش بعد از جایگزینی، قطعی را برای کاربران واقعی شبیه‌سازی می‌کند!).

## چه چیزی عوض شد
- باز شدن صفحه‌ی پخش: وقتی کش گرم است **صفر** درخواست به Supabase (قبلاً ۴ درخواست پشت‌سرهم)؛ وقتی سرد است ۲ رفت‌وبرگشت.
- اگر Supabase در دسترس نباشد، هنرجوی فعلی همچنان لیست دوره‌ها را می‌بیند و ویدیو پخش می‌کند (تا ۱۴ روز داده‌ی کش‌شده)؛ خرید تازه همیشه فوراً دیده می‌شود.
- اگر Supabase نباشد و داده‌ای کش نشده باشد: پیام «سرویس موقتاً در دسترس نیست» (کاربر از حساب خارج نمی‌شود).
- فونت‌ها (Vazirmatn و Fraunces) و `supabase-js` روی هاست خودتان؛ GTM به‌صورت `async` (دیگر صفحه را معطل نمی‌کند).
- صفحه‌ی ورود: ارقام فارسی/عربی خودکار انگلیسی می‌شوند (قبلاً پاک می‌شدند)؛ بعد از ورود به صفحه‌ای که کاربر از آن آمده برمی‌گردد.
- `sitemap.php` اصلاح‌شده (خطای ستون `updated_at`).

## هنوز به Supabase وابسته است (مرحله‌ی بعد)
ورود/OTP تازه، تأیید پرداخت (`verify.php`)، پنل ادمین، بلاگ و دیدگاه‌ها، ویرایش پروفایل.
