# رفع باگ «ثبت شماره موبایل برای کاربران گوگل» (فقط همین، روی نسخه‌ی فعلی سایت)

سه فایل در `public_html` (قبل از جایگزینی از دو فایل قدیمی بکاپ بگیر):
- `check-phone.php`  ← **فایل جدید**؛ قبل از ارسال پیامک چک می‌کند شماره برای حساب دیگری ثبت نشده باشد
- `dashboard.html`   ← کارت ثبت شماره (با کد پیامکی)؛ تب پروفایل خودکار باز می‌شود
- `course.html`      ← خریدار بدون شماره/پروفایل به فرم درست فرستاده می‌شود و بعد از تکمیل برمی‌گردد

هیچ تغییری روی Supabase لازم نیست. بررسی نهایی تکراری‌بودن شماره همچنان در `set_phone` انجام می‌شود.
