# رفع باگ «ثبت شماره موبایل برای کاربران گوگل» (فقط همین، روی نسخه‌ی فعلی سایت)

دو فایل را روی `public_html` جایگزین کن (قبلش از هر دو بکاپ بگیر):
- `dashboard.html`  ← کارت «ثبت شماره موبایل» با کد پیامکی (فقط برای کاربرانی که شماره ندارند)
- `course.html`     ← خریدار بدون شماره/پروفایل مستقیم به فرم درست فرستاده می‌شود و بعد از تکمیل به صفحه‌ی خرید برمی‌گردد

هیچ فایل دیگری عوض نشده. بک‌اند (`set_phone` در user-auth) از قبل وجود دارد.
